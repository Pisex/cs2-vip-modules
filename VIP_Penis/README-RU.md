# [VIP] [Penis](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Penis)

## Добавляет модель в область паха VIP-игрока.

### Ключ возможности

В `groups.ini` добавьте:

```
"penis" 		"1/0"
"penis_model"	"model_path"
```

Пути моделей:

```
models\kolka\penis\penis_weapon.vmdl 	//Knife weapon
models\kolka\penis\penis_small.vmdl
models\kolka\penis\penis_medium.vmdl
models\kolka\penis\penis.vmdl
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `penis`.

```
	"penis"
	{
		"en"	"Penis"
		"ru"	"Пенис"
	}
```
