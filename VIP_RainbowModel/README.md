# [VIP] [Rainbow Model](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_RainbowModel)

## Adds the ability for VIP players to put a colored model

### Feature key

In **groups.ini** add:
```
"rainbow_model" "1/0"
```

### Translation key

In **vip.phrases.txt** add:
```
	"rainbow_model"
	{
		"en"	"Rainbow model"
		"ru"	"Разноцветная модель"
	}
```
