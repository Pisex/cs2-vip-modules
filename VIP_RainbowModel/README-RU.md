# [VIP] [Rainbow Model](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_RainbowModel)

## Позволяет VIP-игрокам использовать разноцветную модель.

### Ключ возможности

В `groups.ini` добавьте:

```
"rainbow_model" "1/0"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `rainbow_model`.

```
	"rainbow_model"
	{
		"en"	"Rainbow model"
		"ru"	"Разноцветная модель"
	}
```
