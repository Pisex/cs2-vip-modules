# [VIP] Rainbow Model

Дозволяє VIP-гравцям використовувати різнокольорову модель.

У `groups.ini` додайте:

```
"rainbow_model" "1/0"
```

У `vip.phrases.txt` додайте ключ `rainbow_model`.

```
	"rainbow_model"
	{
		"en"	"Rainbow model"
		"ru"	"Разноцветная модель"
	}
```
