# [VIP] [Vampirism](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Vampirism)

## Allows players to regenerate health when dealing damage to enemies

### Feature key

In **groups.ini** add:
```
"Vampirism" "10"
```
What percentage of damage will be added to health

### Translation key

In **vip.phrases.txt** add:
```
	"Vampirism"
	{
		"en"	"Vampirism"
		"ru"	"Вампиризм"
	}
```
