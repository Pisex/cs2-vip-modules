# [VIP] Vampirism
My Discord server - https://discord.com/invite/g798xERK5Y

Allows players to regenerate health when dealing damage to enemies

In **groups.ini** add:
```
"Vampirism" "10"
```
What percentage of damage will be added to health

In **vip.phrases.txt** add:
```
	"Vampirism"
	{
		"en"	"Vampirism"
		"ru"	"Вампиризм"
	}
```
