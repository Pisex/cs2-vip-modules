# [VIP] [Vampirism](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Vampirism)

## Відновлює здоров’я VIP-гравця залежно від шкоди, завданої ворогам.

### Налаштування

Додайте можливість до `addons/configs/vip/groups.ini`:

```
"Vampirism" "10"
```

Значення — це відсоток завданої шкоди, який додається до здоров’я VIP-гравця.

### Ключ перекладу

Ключ фрази перекладу: `Vampirism`.

```
	"Vampirism"
	{
		"en"	"Vampirism"
		"ru"	"Вампиризм"
	}
```
