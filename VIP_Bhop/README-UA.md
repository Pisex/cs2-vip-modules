# [VIP] [Bhop](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Bhop)

## Додає VIP-гравцям можливість використовувати bhop.

### Ключ можливості

У `groups.ini` додайте:

```
"bhop" "whether to give bhop(1/0)"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `bhop`.

```
	"bhop"
	{
		"en"	"Bhop"
		"ru"	"Бхоп"
	}
```
