# [VIP] [Bhop](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Bhop)

## Adds bhop option to VIP ability customization.

### Feature key

In **groups.ini** add:
```
"bhop" "whether to give bhop(1/0)"
```

### Translation key

In **vip.phrases.txt** add:
```
	"bhop"
	{
		"en"	"Bhop"
		"ru"	"Бхоп"
	}
```
