# [VIP] [Bhop](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Bhop)

## Добавляет VIP-игрокам возможность использовать bhop.

### Ключ возможности

В `groups.ini` добавьте:

```
"bhop" "whether to give bhop(1/0)"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `bhop`.

```
	"bhop"
	{
		"en"	"Bhop"
		"ru"	"Бхоп"
	}
```
