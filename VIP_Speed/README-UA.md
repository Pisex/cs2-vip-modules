# [VIP] [Speed](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Speed)

## Дозволяє VIP-гравцям змінювати швидкість руху. Допустимий діапазон — від `0.1` до `2.0`; стандартне значення — `1.0`.

### Ключ можливості

У `groups.ini` додайте можливість:

### Налаштування

Діапазон значення швидкості: від `0.1` до `2.0`.

Додайте можливість до `addons/configs/vip/groups.ini`:

```
"VIP"
{
    "speed" "1.1"
}
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ фрази `speed`.
