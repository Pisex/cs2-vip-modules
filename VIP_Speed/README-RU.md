# [VIP] [Speed](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Speed)

## Позволяет VIP-игрокам изменять скорость движения. Допустимый диапазон — от `0.1` до `2.0`; стандартное значение — `1.0`.

### Ключ возможности

В `groups.ini` добавьте возможность:

### Настройка

Допустимый диапазон значения скорости: от `0.1` до `2.0`.

Добавьте возможность в `addons/configs/vip/groups.ini`:

```
"VIP"
{
    "speed" "1.1"
}
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ фразы `speed`.
