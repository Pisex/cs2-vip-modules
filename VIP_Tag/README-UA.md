# [VIP] Tag

Дозволяє VIP-гравцям використовувати тег клану в таблиці рахунку.

## Налаштування

Додайте можливість до `addons/configs/vip/groups.ini`:

```
"clantag" "value"
```

Значення `value` відображається як тег клану VIP-гравця.

Ключ фрази перекладу: `clantag`.

```
	"clantag"
	{
		"en"	"Clan Tag"
		"ru"	"Клан-Тег"
	}
```
