# [VIP] Tag

Позволяет VIP-игрокам использовать тег клана в таблице счёта.

## Настройка

Добавьте возможность в `addons/configs/vip/groups.ini`:

```
"clantag" "value"
```

Значение `value` отображается как тег клана VIP-игрока.

Ключ фразы перевода: `clantag`.

```
	"clantag"
	{
		"en"	"Clan Tag"
		"ru"	"Клан-Тег"
	}
```
