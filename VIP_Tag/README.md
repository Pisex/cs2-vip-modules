# [VIP] Tag
My Discord server - https://discord.com/invite/g798xERK5Y

Adds the ability for VIP players to have a clan tag in TAB

In **groups.ini** add:
```
"clantag" "value"
```

In **vip.phrases.txt** add:
```
	"clantag"
	{
		"en"	"Clan Tag"
		"ru"	"Клан-Тег"
	}
```
