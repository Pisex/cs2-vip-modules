# [VIP] [Tag](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Tag)

## Adds the ability for VIP players to have a clan tag in TAB

### Feature key

In **groups.ini** add:
```
"clantag" "value"
```

### Translation key

In **vip.phrases.txt** add:
```
	"clantag"
	{
		"en"	"Clan Tag"
		"ru"	"Клан-Тег"
	}
```
