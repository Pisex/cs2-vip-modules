# [VIP] [Join Sound](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_JoinSound)

## Відтворює звук для всіх підключених гравців, які не є ботами, коли приєднується VIP-гравець.

### Ключ можливості

У `groups.ini` додайте шлях до звукового файлу:

```ini
"JoinSound" "sounds/music/vip_join.vsnd_c"
```

### Ключ перекладу

У `vip.phrases.txt` додайте мітку `JoinSound`.
