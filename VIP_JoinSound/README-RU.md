# [VIP] [Join Sound](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_JoinSound)

## Воспроизводит звук для всех подключённых игроков, не являющихся ботами, когда присоединяется VIP-игрок.

### Ключ возможности

В `groups.ini` добавьте путь к звуковому файлу:

```ini
"JoinSound" "sounds/music/vip_join.vsnd_c"
```

### Ключ перевода

В `vip.phrases.txt` добавьте метку `JoinSound`.
