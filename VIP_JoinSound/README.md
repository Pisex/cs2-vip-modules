# [VIP] Join Sound

Plays a sound for all connected non-bot players when a VIP joins.

In `groups.ini` add the path to a sound file:

```ini
"JoinSound" "sounds/music/vip_join.vsnd_c"
```

In `vip.phrases.txt` add the `JoinSound` feature label.
