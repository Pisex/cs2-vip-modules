# [VIP] [Colored Smoke](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Smoke)

## Adds the ability for VIP players to have multi-colored smoke

### Feature key

In **groups.ini** add:
```
"smoke_color" "random or rgb color"
```

### Translation key

In **vip.phrases.txt** add:
```
	"smoke_color"
	{
		"en"	"Colored smoke"
		"ru"	"Цветной смок"
	}
```
