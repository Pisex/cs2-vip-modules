# [VIP] [Respawn](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Respawn)

## Adds the ability for a VIP player to revive

### Commands

Commands: `mm_respawn`, `sm_respawn`, `respawn` and `!respawn`.

### Translation key

The module also uses the translation keys `YourAlive`, `SelectTeam`, `EndRound` and `LimitRespawn`.

### Feature key

In **groups.ini** add:
```
"respawn" "respawn value"
```

### Translation key

In **vip.phrases.txt** add:
```
	"respawn"
	{
		"en"	"Respawn"
		"ru"	"Респавн"
	}
```
