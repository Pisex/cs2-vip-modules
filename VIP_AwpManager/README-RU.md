# [VIP] Awp Manager

Позволяет VIP-игрокам изменять количество патронов AWP в магазине.

В `groups.ini` добавьте:

```
"awp_manager" "count"
```

В `vip.phrases.txt` добавьте ключ `awp_manager`.

```
	"awp_manager"
	{
		"en"	"AWP Manager"
		"ru"	"AWP Manager"
	}
```
