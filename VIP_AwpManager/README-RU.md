# [VIP] [Awp Manager](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_AwpManager)

## Позволяет VIP-игрокам изменять количество патронов AWP в магазине.

### Ключ возможности

В `groups.ini` добавьте:

```
"awp_manager" "count"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `awp_manager`.

```
	"awp_manager"
	{
		"en"	"AWP Manager"
		"ru"	"AWP Manager"
	}
```
