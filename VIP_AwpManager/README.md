# [VIP] [Awp Manager](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_AwpManager)

## Adds the ability to change the number of AWP rounds in the clip.

### Feature key

In **groups.ini** add:
```
"awp_manager" "count"
```

### Translation key

In **vip.phrases.txt** add:
```
	"awp_manager"
	{
		"en"	"AWP Manager"
		"ru"	"AWP Manager"
	}
```
