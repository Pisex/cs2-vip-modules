# [VIP] [Awp Manager](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_AwpManager)

## Дозволяє змінювати кількість набоїв AWP у магазині для VIP-гравців.

### Ключ можливості

У `groups.ini` додайте:

```
"awp_manager" "count"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `awp_manager`.

```
	"awp_manager"
	{
		"en"	"AWP Manager"
		"ru"	"AWP Manager"
	}
```
