# [VIP] Awp Manager

Дозволяє змінювати кількість набоїв AWP у магазині для VIP-гравців.

У `groups.ini` додайте:

```
"awp_manager" "count"
```

У `vip.phrases.txt` додайте ключ `awp_manager`.

```
	"awp_manager"
	{
		"en"	"AWP Manager"
		"ru"	"AWP Manager"
	}
```
