# [VIP] No Fall Damage

Позволяет VIP-игрокам отключить урон от падения.

В `groups.ini` добавьте:

```ini
"nofalldamage" "1"
```

Используйте `1`, чтобы включить возможность, и `0`, чтобы отключить её. В `vip.phrases.txt` добавьте метку `nofalldamage`.
