# [VIP] [No Fall Damage](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_NoFallDamage)

## Дозволяє VIP-гравцям вимкнути шкоду від падіння.

### Ключ можливості

У `groups.ini` додайте:

```ini
"nofalldamage" "1"
```

### Ключ перекладу

Використовуйте `1`, щоб увімкнути можливість, і `0`, щоб вимкнути її. У `vip.phrases.txt` додайте мітку `nofalldamage`.
