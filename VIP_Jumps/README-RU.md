# [VIP] [Jumps](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Jumps)

## Добавляет VIP-игроку дополнительные прыжки.

### Ключ возможности

В `groups.ini` добавьте:

```
"jumps" "count jumps"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `jumps`.

```
	"jumps"
	{
		"en"	"Jumps"
		"ru"	"Прыжки"
	}
```
