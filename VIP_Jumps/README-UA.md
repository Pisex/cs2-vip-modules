# [VIP] [Jumps](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Jumps)

## Додає VIP-гравцеві додаткові стрибки.

### Ключ можливості

У `groups.ini` додайте:

```
"jumps" "count jumps"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `jumps`.

```
	"jumps"
	{
		"en"	"Jumps"
		"ru"	"Прыжки"
	}
```
