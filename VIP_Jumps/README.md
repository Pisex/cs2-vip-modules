# [VIP] [Jumps](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Jumps)

## Gives extra jumps to a VIP player

### Feature key

In **groups.ini** add:
```
"jumps" "count jumps"
```

### Translation key

In **vip.phrases.txt** add:
```
	"jumps"
	{
		"en"	"Jumps"
		"ru"	"Прыжки"
	}
```
