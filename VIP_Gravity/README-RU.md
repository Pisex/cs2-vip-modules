# [VIP] [Gravity](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Gravity)

## Позволяет VIP-игрокам изменять уровень гравитации. Допустимый диапазон — от `0.1` до `2.0`; стандартное значение — `1.0`.

### Ключ возможности

В `groups.ini` добавьте:

```
"gravity" "1.0"
```

### Ключ перевода

В `vip.phrases.txt` добавьте метку `gravity`.
