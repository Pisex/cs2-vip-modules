# [VIP] [Gravity](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Gravity)

## Дозволяє VIP-гравцям змінювати рівень гравітації. Допустимий діапазон — від `0.1` до `2.0`; стандартне значення — `1.0`.

### Ключ можливості

У `groups.ini` додайте:

```
"gravity" "1.0"
```

### Ключ перекладу

У `vip.phrases.txt` додайте мітку `gravity`.
