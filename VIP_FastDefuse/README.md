# [VIP] [Fast Defuse](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FastDefuse)

## Adds the ability for VIP players to defuse a bomb faster

### Feature key

In **groups.ini** add:
```
"fd" "50"
```
50 - how many percent faster will the bomb be defused

### Translation key

In **vip.phrases.txt** add:
```
    "fd"
    {
        "en"    "Fast Defuse"
        "ru"    "Быстрое Обезвреживание"
    }
```
