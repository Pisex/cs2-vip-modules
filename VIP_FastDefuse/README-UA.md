# [VIP] [Fast Defuse](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FastDefuse)

## Додає VIP-гравцям можливість швидше знешкоджувати бомбу.

### Ключ можливості

У `groups.ini` додайте:

```
"fd" "50"
```

`50` означає, на скільки відсотків скорочується час знешкодження.

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `fd`.

```
    "fd"
    {
        "en"    "Fast Defuse"
        "ru"    "Быстрое Обезвреживание"
    }
```
