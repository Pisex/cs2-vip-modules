# [VIP] [Endurance](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Endurance)

## When shooting at a VIP player, he will not be slowed down

### Feature key

In **groups.ini** add:
```
"Endurance" "0/1"
```

### Translation key

In **vip.phrases.txt** add:
```
	"Endurance"
	{
		"en"	"Endurance"
		"ru"	"Выносливость"
	}
```
