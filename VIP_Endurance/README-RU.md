# [VIP] [Endurance](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Endurance)

## При стрельбе по VIP-игроку он не замедляется.

### Ключ возможности

В `groups.ini` добавьте:

```
"Endurance" "0/1"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `Endurance`.

```
	"Endurance"
	{
		"en"	"Endurance"
		"ru"	"Выносливость"
	}
```
