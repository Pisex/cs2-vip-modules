# [VIP] [Endurance](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Endurance)

## Під час стрільби по VIP-гравцю він не сповільнюється.

### Ключ можливості

У `groups.ini` додайте:

```
"Endurance" "0/1"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `Endurance`.

```
	"Endurance"
	{
		"en"	"Endurance"
		"ru"	"Выносливость"
	}
```
