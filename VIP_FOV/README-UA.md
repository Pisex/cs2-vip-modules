# [VIP] [FOV](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FOV)

## Дозволяє VIP-гравцям змінювати поле зору.

### Ключ можливості

У `groups.ini` додайте значення через кому:

```
"FOV" "100,90,80,70,60"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключі `FOV` і `FOV_Title`.

```
	"FOV"
	{
		"en"	"Viewing angle"
		"ru"	"Угол обзора"
	}
	"FOV_Title"
	{
		"en"	"Select FOV"
		"ru"	"Выберите FOV"
	}
```
