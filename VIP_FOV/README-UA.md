# [VIP] FOV

Дозволяє VIP-гравцям змінювати поле зору.

У `groups.ini` додайте значення через кому:

```
"FOV" "100,90,80,70,60"
```

У `vip.phrases.txt` додайте ключі `FOV` і `FOV_Title`.

```
	"FOV"
	{
		"en"	"Viewing angle"
		"ru"	"Угол обзора"
	}
	"FOV_Title"
	{
		"en"	"Select FOV"
		"ru"	"Выберите FOV"
	}
```
