# [VIP] [FOV](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FOV)

## Allows VIP players to change their viewing angle

### Feature key

In **groups.ini** add:
```
"FOV" "100,90,80,70,60"
```
Values separated by commas

### Translation key

In **vip.phrases.txt** add:
```
	"FOV"
	{
		"en"	"Viewing angle"
		"ru"	"Угол обзора"
	}
	"FOV_Title"
	{
		"en"	"Select FOV"
		"ru"	"Выберите FOV"
	}
```
