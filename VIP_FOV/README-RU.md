# [VIP] [FOV](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FOV)

## Позволяет VIP-игрокам изменять поле зрения.

### Ключ возможности

В `groups.ini` добавьте значения через запятую:

```
"FOV" "100,90,80,70,60"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключи `FOV` и `FOV_Title`.

```
	"FOV"
	{
		"en"	"Viewing angle"
		"ru"	"Угол обзора"
	}
	"FOV_Title"
	{
		"en"	"Select FOV"
		"ru"	"Выберите FOV"
	}
```
