# [VIP] FOV

Позволяет VIP-игрокам изменять поле зрения.

В `groups.ini` добавьте значения через запятую:

```
"FOV" "100,90,80,70,60"
```

В `vip.phrases.txt` добавьте ключи `FOV` и `FOV_Title`.

```
	"FOV"
	{
		"en"	"Viewing angle"
		"ru"	"Угол обзора"
	}
	"FOV_Title"
	{
		"en"	"Select FOV"
		"ru"	"Выберите FOV"
	}
```
