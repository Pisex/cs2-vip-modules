# [VIP] [DuckSpeed](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_DuckSpeed)

## Позволяет VIP-игрокам изменять скорость приседания.

### Ключ возможности

В `groups.ini` добавьте:

```
"duckspeed" "10.0"
```

Значение определяет скорость приседания.
