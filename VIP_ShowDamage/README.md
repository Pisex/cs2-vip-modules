# [VIP] [Show Damage](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_ShowDamage)

## Added the ability for VIP players to receive information about the amount of damage done

### Feature key

In **groups.ini** add:
```
"show_damage" "whether to give access(1/0)"
```

### Translation key

In **vip.phrases.txt** add:
```
	"show_damage"
	{
		"en"	"Show damage"
		"ru"	"Показ урона"
	}
```
