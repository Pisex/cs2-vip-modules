# [VIP] [Fortnite Hits](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_Fortnite_Hits)

## З'єднує VIP-доступ із плагіном Fortnite Hits. Цей модуль сам не показує шкоду, а викликає зовнішній `IFortniteHitsApi` для надання або відкликання доступу VIP-гравцям.

Перед цим модулем установіть і завантажте плагін Fortnite Hits.

### Ключ можливості

У `groups.ini` додайте:

```
"fortnite_hits" "1/0"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `fortnite_hits`.

```
"fortnite_hits"
{
    "en" "Damage Display"
    "ru" "Отображение урона"
}
```
