# [VIP] AntiFlash

Додає VIP-гравцям можливість не засліплюватися від власних гранат та гранат союзників.

У `groups.ini` додайте:

```
"antiflash" "value"
```

**Можливі значення:**

- 1 — не засліплюватися від команди;
- 2 — не засліплюватися від власної гранати;
- 3 — не засліплюватися від команди та власної гранати;
- 4 — повністю вимкнути засліплення.

У `vip.phrases.txt` додайте ключ `antiflash`.

```
	"antiflash"
	{
		"en"	"Anti-Flash"
		"ru"	"Антифлеш"
	}
```
