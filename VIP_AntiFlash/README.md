# [VIP] [AntiFlash](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_AntiFlash)

## Adds to VIP the ability for VIP players to not receive blinding from themselves and/or allies.

### Feature key

In **groups.ini** add:
```
"antiflash" "value"
```
**Possible values:**
- 1 - No blinding from the team
- 2 - No blinding from self
- 3 - No blinding from team and self
- 4 - No dazzle at all

### Translation key

In **vip.phrases.txt** add:
```
	"antiflash"
	{
		"en"	"Anti-Flash"
		"ru"	"Антифлеш"
	}
```
