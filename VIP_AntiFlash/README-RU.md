# [VIP] [AntiFlash](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_AntiFlash)

## Добавляет VIP-игрокам возможность не ослепляться от собственных гранат и гранат союзников.

### Ключ возможности

В `groups.ini` добавьте:

```
"antiflash" "value"
```

**Возможные значения:**

- 1 — не ослепляться от команды;
- 2 — не ослепляться от собственной гранаты;
- 3 — не ослепляться от команды и собственной гранаты;
- 4 — полностью отключить ослепление.

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `antiflash`.

```
	"antiflash"
	{
		"en"	"Anti-Flash"
		"ru"	"Антифлеш"
	}
```
