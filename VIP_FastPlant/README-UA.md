# [VIP] Fast Plant

Дозволяє VIP-гравцю швидше встановлювати бомбу.

У `groups.ini` додайте:

```
"fp" "0/1"
```

У `vip.phrases.txt` додайте ключ `fp`.

```
    "fp"
    {
        "en"    "Fast Plant"
        "ru"    "Быстрое закладка бомбы"
    }
```
