# [VIP] [Fast Plant](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FastPlant)

## Дозволяє VIP-гравцю швидше встановлювати бомбу.

### Ключ можливості

У `groups.ini` додайте:

```
"fp" "0/1"
```

### Ключ перекладу

У `vip.phrases.txt` додайте ключ `fp`.

```
    "fp"
    {
        "en"    "Fast Plant"
        "ru"    "Быстрое закладка бомбы"
    }
```
