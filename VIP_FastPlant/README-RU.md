# [VIP] Fast Plant

Позволяет VIP-игроку быстрее устанавливать бомбу.

В `groups.ini` добавьте:

```
"fp" "0/1"
```

В `vip.phrases.txt` добавьте ключ `fp`.

```
    "fp"
    {
        "en"    "Fast Plant"
        "ru"    "Быстрое закладка бомбы"
    }
```
