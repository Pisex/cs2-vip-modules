# [VIP] [Fast Plant](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FastPlant)

## Позволяет VIP-игроку быстрее устанавливать бомбу.

### Ключ возможности

В `groups.ini` добавьте:

```
"fp" "0/1"
```

### Ключ перевода

В `vip.phrases.txt` добавьте ключ `fp`.

```
    "fp"
    {
        "en"    "Fast Plant"
        "ru"    "Быстрое закладка бомбы"
    }
```
