# [VIP] [Fast Plant](https://github.com/bywinsty/cs2-vip-modules/tree/dev/VIP_FastPlant)

## Allows a VIP player to quickly place a bomb

### Feature key

In **groups.ini** add:
```
"fp" "0/1"
```

### Translation key

In **vip.phrases.txt** add:
```
    "fp"
    {
        "en"    "Fast Plant"
        "ru"    "Быстрое закладка бомбы"
    }
```
